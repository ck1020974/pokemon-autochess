# 敵方角色與場景對應表

更新：2026-10-26。依現行程式實際計算；不使用訓練家原作屬性推測。

玩家選的訓練家不影響場景。五色競技場保留給四天王階段與小智；冠軍戰優先使用三色殿堂。其他一般角色依敵方定義中的核心寶可夢羈絆判斷：至少一半核心成員符合才採用主題，多主題同分時依熱風→潮旋→吸取／蟲咬→降雪→挖洞→念力／詛咒優先。這不是要求羈絆已發動；一隻核心也可能決定場景。

戰鬥場景只在確認對手後抽一次，開場與對戰共用。可選時避開最近兩場，候選不足時先避開上一場；單場景主題仍可能連續出現。

四天王階段（8～11 勝）與一般戰的小智一律抽競技場：青藍、珊瑚、薄荷、薰衣草、金砂。冠軍戰（12 勝起，含小智）一律抽殿堂：青藍、薰衣草、白金。電光／堅硬不再指定競技場；一般隨機池只有鄉間道路、森林、海港、草原、沙漠、海灘。

下表列出一般戰（0～7 勝）的所有核心隊伍定義。初階為 0～2 勝、中階為 3～4 勝、高階為 5～7 勝；名稱後的編號可區分同名不同隊伍。
