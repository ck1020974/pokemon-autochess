# 手機整頁滑動修正（2026-11-07）

先前手機樣式以 body overflow-y:auto 讓短螢幕能操作下方按鈕，但上方資訊列同屬頁面捲動。844×390、安全區 top=44 時，重現 window.scrollY=204、header.top=-154；旋轉才恢復並不能避免下一次滑動。

手機改用固定的 html/body 外框，body 高度隨 100dvh 更新。root 在安全區內提供固定高度，遊戲容器保留必要的內部垂直捲動，上方資訊列 sticky 固定在容器頂端。頂列採不透明底色，避免下方內容捲過時影響閱讀。商店維持獨立橫向捲動，遮罩與角色詳情仍使用原固定定位。

伊布說明恢復「合成時額外獲得兩倍經驗值且隨機進化。」；加權進化邏輯保持不變。

驗證：

- 新增 verify-mobile-scroll-lock.mjs：先在舊版重現頁面位移及頂列消失，再檢查觸控滑動、滾輪、程式捲動、直橫向尺寸切換及動態安全區，頁面保持 scrollY=0；頂列、下方按鈕與商品橫滑均可用。
- verify-mobile-safe-area.mjs 的原生遊戲測試新增實際觸控滑動與殘留捲動要求，逐次確認頁面不位移、資訊列不進入安全區。
- verify-mobile-unit-sizes.mjs 保留雙方完整五隻、空第5槽、羈絆錨點與商店尺寸檢查；伊布進化行為測試保持。
- 證據保存於 output/mobile-scroll-lock-20261107/ 與既有手機驗證目錄。測試使用 Chrome／CDP 觸控及安全區模擬，並非 iPhone 實機測試。
