# 2026-11-06 永久成長、EXP 與背景模擬修正

依前次遊戲審查順序修正四項既有錯誤：

1. 正式／背景戰鬥的永久成長先按原件上限寫回，再判斷戰鬥副本是否已達上限。暫時攻擊50的波克比，其原件攻40仍會永久成長至42；生命與60上限同理，不會重複成長。
2. EXP獎勵只增加獎勵標示的EXP，透過既有升級邏輯處理達門檻的進化，不再假造一隻帶EXP的合成素材。跨3／9、一次跨多階、伊布、已滿三星均涵蓋；EXP獎勵不觸發猴怪等合成專屬招式，實際合成流程維持原規則。
3. 雪笠怪／暴雪王背景模擬按一／二／三星永久加攻1／2／5，與正式戰鬥一致，封印時不觸發。
4. 背景模擬使用現行蟲咬規則：羈絆達2後，未被封印的存活擊殺者永久+1生命，取代已過期的Claw加攻分支。涵蓋雙側隊伍、未達門檻、封印、戰鬥副本已達上限及同一敵人不重複發獎勵。

回歸指令：`npm run test:growth-exp-parity`。也可加參數單獨執行第1～4組：`node scripts/verify-growth-exp-parity.mjs 1`。

新增56個行為案例（16／12／12／16），每組均先確認舊程式重現失敗，再修正並通過。原有戰鬥與獎勵回歸及正式建置另行執行。本次僅更新正式遊戲，保留影片與錄影副本。
