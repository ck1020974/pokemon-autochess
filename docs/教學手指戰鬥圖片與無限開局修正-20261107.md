# 教學手指、戰鬥圖片與無限開局修正

依作者在七項修正發布後的四項回饋實作。

## 完成內容

1. **無限模式第一輪直接開局**：固定十二隻御三家保留，其餘原先要手選五次的一階角色改為隨機抽五隻，不重複、不包含隱藏或版本外角色。第一輪直接進商店；重進商店與刷新不會再抽一次。第二、三、六、十輪的手動選角排程保留。
2. **教學手指不再被遮住**：原生手指所在槽位層級低於被提高層級的羈絆列，即使偽元素本身有很高 z-index，仍會被父層壓住。現在提高正確的同層槽位；另量測資訊列與槽位實際位置，替完整15px跳動範圍保留上方空間，隨縮放、轉向、捲動與選取重新量測。保留原生手指、動畫與角色站位。
3. **小剛戰鬥圖片修正**：教學隊伍的提前返回路徑漏掉一般敵隊最後的戰鬥圖切換，導致戰鬥沿用商店立繪00。現在建立教學隊伍時就套用對應戰鬥圖01；預覽仍使用00，兩個引擎複製與實際畫面均核對單位ID、圖片與五個邏輯槽位。
4. **難度卡視覺調整**：移除普通／困難的鎖定說明文字，整張卡片灰化並保持不可點選；可選的簡單卡使用同一個教學柔光動畫。降低動態效果偏好時保留靜態柔光。手機的教學選擇遮罩置於背景資訊列之上，標題不再被遮住。後續冠軍教學不受首戰限制影響。
