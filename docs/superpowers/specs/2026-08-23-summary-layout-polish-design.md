# 結算畫面排版微調設計

## 目標

讓結算畫面的資訊由左至右自然閱讀、減少隊伍分頁的垂直空白，並保留完整的對戰與成就資訊。

## 上排資訊列

- 保留主角頭像與名稱群組。
- 名稱群組右方留出固定間距後，依序顯示難度圖示、既有數據（場數、勝／平／敗、勝率）與四個操作按鈕。
- 數據維持三個欄位，欄位間有可隨視窗寬度調整的間距。
- 隊伍、對戰、成就、重啟按鈕改為同高度的橫向長方形；桌面版維持單列，窄螢幕可換行且不溢出。

## 隊伍分頁

- 我方隊伍與敵方隊伍切換按鈕放進隊伍內容的第一列，與既有羈絆圖示共同排列。
- 僅顯示被選取的一方；我方與敵方使用相同的面板間距，敵方不保留額外的上方空白。
- 保持寶可夢卡片的橫向 flex 排列，讓卡片可盡可能上移且不超出內容背景。

## 對戰分頁

- 顯示完整 `battleHistory`，不再截斷為最後 12 場。
- 每列維持 12 個圖示並自動增加列數；容器保留可捲動內容區，以容納長局數紀錄。
- 現有勝利彩色、敗北與平手灰階的視覺規則不變。

## 成就分頁

- 第一格移除特殊色、鎖定感或高亮效果，四格共用相同底色、邊框與陰影規則。
- 圖示下方的角色名稱放大，並增加與圖示的垂直距離。

## 角色選擇畫面

- 訓練家名稱從圖示下方移到圖示上方。
- 名稱與圖示的垂直間距略微縮小，保留現有輪播與已選取的視覺強調。

## 驗證

- 更新既有 `scripts/verify-trainer-presentation.mjs` 的來源／樣式斷言。
- 執行 `npm run test:trainer-presentation`、`npm run lint` 與 `npm run build`。
