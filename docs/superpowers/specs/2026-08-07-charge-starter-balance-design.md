# 電光與初始夥伴平衡調整設計

日期：2026-08-07

## 目標

降低電光羈絆在低星關卡的開戰爆發，並修正初始夥伴五層效果與介面說明不一致的問題。

## 範圍

### 電光（Charge）

- 啟動門檻維持 `[2/3/5]`。
- 每個電光角色在戰鬥開始時的隨機攻擊加成改為：
  - 2 層：`0–3`
  - 3 層：`2–6`
  - 5 層：`6–12`
- 更新羈絆文字，完整列出三個區間。
- 同步更新正式戰鬥模擬器與無介面模擬器，避免遊戲與平衡測試規則不同。

### 初始夥伴（Starter）

- 五層永久加成由目前無介面模擬器中的 `+3 HP / +3 攻擊` 修正為 `+2 HP / +2 攻擊`。
- 三層效果維持 `+1 / +1`。
- 正式遊戲既有的準備結束階段規則與文字不變；調整只讓無介面模擬器符合該規則。

## 明確不調整

- 炎帝與水君的能力與數值。
- 其他羈絆、角色、關卡組合與難度標籤。

## 驗證

1. 先新增一個數值檢查，確認兩個戰鬥模擬器都使用新的電光範圍，且無介面模擬器的 Starter 五層為 `+2/+2`。
2. 執行該檢查並確認它在調整前失敗、調整後通過。
3. 執行 `npm run test:smoke` 與 `npm run build`。
