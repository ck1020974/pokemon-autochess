# 選擇與結算版面調整設計

## 範圍

只調整網頁版 UI 與文案資料來源；不變更遊戲數值、角色數值、羈絆或戰鬥規則。

## 角色選擇與無限角色池

- 角色選擇的說明文字改用圖鑑所使用的角色描述來源，避免重複維護。
- 無限角色池維持三欄卡片，增加欄間距。
- 卡片中的角色名稱與羈絆圖示視為一個水平群組並置中；說明保留在其下方。

## 對手選擇

- 對手卡維持直向閱讀順序：立繪、適度間距、名稱。
- 縮短卡片高度，將立繪與名稱整體上移，避免卡片下方留白過大。

## 結算面板

- 主角識別區只呈現立繪、標籤與主角名稱，不再重複顯示成功或失敗狀態。
- 同一列從左至右依序為：主角資訊、難度圖示、三項戰績資料、兩個方形切換鈕（隊伍／對戰）、長方形重新開始按鈕。
- 壓縮面板高度，讓資訊列與內容區更接近。
- 對戰紀錄中的我方主角卡只保留立繪；歷程中的下方資訊統一成短格式，避免重複名稱與雜亂數字。

## 驗證

- 更新 UI 呈現檢查，鎖定文案、元素類別與版面規則。
- 執行 lint、呈現檢查、平衡數值檢查、smoke test、正式建置及本機瀏覽器流程。
