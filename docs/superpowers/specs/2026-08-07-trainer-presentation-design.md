# 訓練家選擇與戰鬥演出設計

## 目標

讓遊戲從開局到進入戰鬥更接近寶可夢對戰的節奏：玩家選擇一名純視覺的訓練家，戰鬥前以環境場景與雙方訓練家進行短暫對決演出。此功能不得影響任何單位、羈絆、商店、敵方隊伍、難度、勝敗或數值。

## 使用者流程

1. 新局開始時，原有教學照常顯示。
2. 玩家完成或點擊「跳過」教學後，顯示「請選擇你的角色」。
3. 選角介面是一列可水平捲動、可用滑鼠拖曳或觸控滑動的角色卡。角色為：小青、小春、小悠、小智、小遙、克麗絲、阿響、琴音、葉子、赤紅。
4. 卡片只顯示簡化後的名稱；程式資源檔名中的 `01`、`02` 不會出現在畫面上。
5. 點選一名角色後才進入既有的角色池選擇與遊戲流程。選擇僅保存在本次遊戲 UI state，不寫入戰鬥模型。
6. 每次已選擇對手、即將開始戰鬥時，先播放戰鬥開場，結束後才顯示既有棋盤與隊伍。

## 戰鬥開場

### 背景

背景依「訓練家個性／關卡」決定，而不是玩家羈絆或隊伍屬性。

- 一般訓練家使用明亮的路線、道館外圍、城市或自然場景。
- 四天王使用各自辨識度高的室內／特殊地形場景。
- 冠軍使用專屬聯盟殿堂／冠軍舞台場景。
- 場景是整個對戰區域的底圖，包含遠景、地面、薄霧與景深；棋盤置於場景上，而非放在一塊不透明的彩色面板上。
- 為維持可讀性，僅允許非常淡的邊緣暗角、地面接觸陰影與局部薄霧。禁止大面積、硬邊的半透明色塊或廉價手遊式漸層卡片。

### 動畫與跳過

- 一般戰鬥採原作風格的短開場，約 1.3–1.6 秒。
- 四天王與冠軍沿用同一構圖，停留延長至約 2 秒。
- 玩家頭像／立繪由左側進場，敵方立繪由右側進場，中間顯示短暫的對決提示，隨後以擦拭或推鏡無縫進入棋盤。
- 只要點擊／觸碰演出區域一次，立即跳過至戰鬥，不需要再次確認。
- 設定提供「快速對戰演出」切換；開啟時保留同一資訊，但縮短至約 0.6 秒。
- 啟用 reduced-motion 時不播放位移與推鏡，立即以靜態場景淡入後進入棋盤。

## 技術邊界

- 新增獨立的訓練家資料、選角元件、戰鬥開場元件與專屬樣式，避免繼續堆疊 `App.tsx` 的 inline styles。
- 使用現有素材：
  - `public/gym/小青.webp`
  - `public/gym/小春.webp`
  - `public/gym/小悠01.webp`
  - `public/gym/小智.webp`
  - `public/gym/小遙01.webp`
  - `public/gym/克麗絲01.webp`
  - `public/gym/阿響01.webp`
  - `public/gym/琴音01.webp`
  - `public/gym/葉子01.webp`
  - `public/champion/赤紅01.webp`
- 背景先以可程式化的 CSS 環境層實作（天空、遠景、地面、霧與暗角），不新增或下載外部圖片；各類關卡使用不同的場景 token。
- 擴充的對手顯示資料只用於選擇場景與判斷一般／四天王／冠軍的演出時長，不能被 `BattleSimulator`、`GameLoop` 或平衡模擬讀取。
- 開場元件只在對手隊伍與玩家訓練家已知後顯示；元件卸載或跳過時必須清除 timeout，避免重複進入戰鬥。

## 驗收與測試

- 純函式測試：角色顯示名稱不含檔名尾碼；對手級別正確對應演出時長與場景類別；快速模式與 reduced-motion 的時長正確。
- 元件測試：跳過會只觸發一次完成回呼；正常計時也只觸發一次；角色選擇回傳指定角色。
- 回歸：現有 `test:smoke`、`test:balance-values`、TypeScript build 都通過；兩個平衡測試證明本功能未改變既有平衡常數。
- 手動：從教學跳過到選角、角色池、一般戰鬥、四天王／冠軍戰與快速模式各走一遍；桌面與窄螢幕都能操作。

## 非目標

- 不加入角色能力、初始寶可夢、數值加成、羈絆加成或新貨幣。
- 不依玩家隊伍、羈絆或屬性動態更換背景。
- 不替換既有角色或對手立繪，不新增外部授權素材。
