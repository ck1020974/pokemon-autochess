# 統一選擇卡片 Implementation Plan

**Goal:** 套用作者核准的第三版示意，角色羈絆僅顯示圖示，上傳正式遊戲。
**Architecture:** 共用卡片元件及兩次點選 hook；選擇彈層共用 CSS，不修改戰鬥與羈絆定位。
**Tech Stack:** React 19 / TypeScript / CSS / Playwright。

## Constraints
- 三種卡片桌面 260×360，標題位置字級一致，深灰底、選中深藍。
- 角色保留圖片、名稱、羈絆圖示及原技能；沒有階級或勾選。
- 對手保留原難度、名稱、圖片，下方三個 coreUnits 代表角色，不抽取實際對戰隊伍。
- 角色／對手先選中再點同一卡片確認；換卡只切換選中；新一批重設；確認只能觸發一次。
- 獎勵保留原文字、暫時標記與單次領取。
- 響應式統一尺寸，手機橫向縮小，直向可捲動，保留鍵盤與羈絆說明。
