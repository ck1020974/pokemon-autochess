# 手機角色、伊布加權與對手難度調整

1. 手機：以真實遊戲、雙方五槽及iPhone安全區量測過小原因。隊伍保留固定五個邏輯槽與雙側第5槽羈絆錨點，圖片可有限重疊但兩隊不可交錯；商品保持可讀尺寸，僅商品區橫滑，不以全頁溢出或縮小到難辨識換取七格同屏。
2. 伊布：排除進化本體及八型共用接棒，沿用遊戲羈絆計數；全隊最高羈絆對應型態的權重2、其他1，並列皆加權，最高沒有對應型態時維持均勻。單次進化抽一次、升三星不重新抽。
3. 對手：以未擊敗者為唯一來源，盡量選三種不同標籤並由低至高排列；種類／人數不夠時不重用已擊敗者。無限模式冠軍戰保留隨機選項，不強制三種難度。使用者已確認接受不足三種。
4. 校準：舊報告未用實際敵隊，不能直接套用。以現行正式BattleSimulator、createEnemyTeam與各模式倍率、多樣合法購買／合成基準及固定種子重新量測333個NPC定義；普通／超級／高級／大師分開分級。保存勝／敗／平／超時、方法限制及報告，不改敵隊數值來迎合標籤。
5. 整合：執行行為測試、手機尺寸／安全區／雙側錨點與實際選擇→出場→戰鬥檢查，審查後部署並核對正式站。保留v9影片與錄影副本。
