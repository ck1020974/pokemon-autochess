# 作者統計頁實作計畫

**目標：**優先提供作者可登入查看的全站遊玩、完成情況、隊伍與羈絆統計。玩家不需註冊，不製作續玩功能。

**架構：**GitHub Pages 繼續承載遊戲；獨立 Supabase 專案 `jhyqpizbvbwikvalqxpy` 保存匿名事件。寫入端只接受經驗證的事件並去重；資料庫 RLS 限制只有作者會員讀取。依作者後續指示，統計頁使用獨立 `author-report-c9e84b67a2d1.html`，不在遊戲放入口；以電子郵件／密碼登入，不在前端保存作者密碼或管理金鑰。

**統計定義：**台灣時區每日彙整。造訪以同分頁 30 分鐘為一段；不同匿名瀏覽器識別碼估計活躍玩家；完成第一場正式戰鬥才計入遊玩局次。教學、本機開發與自動測試預設不進正式統計。戰鬥勝率含平手；通關率以已完成整局為分母；完成率以合格遊玩局次為分母。明確重新開始及 24 小時無更新列為未完成；期間內未結束列為進行中。樣本數必須顯示，不回填部署前資料。

**固定介面：**`src/analytics/types.ts` 定義 `DashboardFilters`、`DashboardData`；`src/analytics/authorApi.ts` 提供 `authorClient`、`isAuthor()`、`fetchDashboard(filters)`。`src/analytics/collector.ts` 提供不依賴 React 的追蹤器及匿名傳送佇列。App 在實際戰鬥初始化及結果確定時呼叫，重開時結束前局。

全域限制：保留尚未提交的小火龍戰鬥調整，不修改已核准影片與錄影副本。服務角色／secret key 僅在伺服器使用。公開客戶端只能傳送事件，不能任意查詢玩家資料。統計屬瀏覽器回報的趨勢分析，不宣稱精確自然人人數或權威競賽成績。

補充：活躍玩家依選定日期內完成的任一戰鬥計數，跨午夜的持續局次仍計入當日活躍玩家。離線佇列最多保留 500 筆、七天內事件；過期紀錄不阻擋新事件。此次另依作者要求更新小偷為隨機偷取 2／5 點攻擊或生命，保留雙方規則、永久成長與最低 1 點。
