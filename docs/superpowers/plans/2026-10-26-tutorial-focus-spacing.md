# 教學進場、操作焦點與陣容間距

使用者指定四項：教學也要有雙方進場；加深教學背景並讓操作目標發光；拉開桌機兩隊與隊內間距；我方羈絆左緣對齊最後排角色左緣、敵方右緣對齊最後排角色右緣並向內排列。

原因：教學從標題直接開始沒有選訓練家，selectedTrainer 為 null 會跳過 Intro；原 .16 遮罩偏淡且舊發光 keyframe 使用無效的 !important；桌機角色仍有負 margin；羈絆仍置中。

方案：教學沿用已選訓練家，未選用小青，重置待開始隊伍。遮罩 .52、金色靜態外框與緩慢光暈，鎖定／戰鬥／購買／關閉等下一步目標都保持可點。桌機專用寬版戰場、較大兩隊間距、取消角色負 margin，手機保持緊湊。

羈絆以初始／備戰隊伍最後一個非空位置為錨點，透過 layout offset 與 ResizeObserver 對齊實際圖片邊緣，不追隨攻擊位移；縮放時重算，避免手機負 margin 與空格造成偏差。
