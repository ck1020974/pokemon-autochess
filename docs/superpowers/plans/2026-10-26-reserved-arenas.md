# 競技場保留規則

使用者指定五色競技場只提供四天王與小智。沿用先前冠軍戰殿堂要求，優先序為：冠軍戰三色殿堂 → 四天王階段或小智五色競技場 → 其他一般角色依既有主題或一般隨機池。移除電光／堅硬的競技場映射，也移除一般隨機池中的競技場。

以選敵資料的角色名稱識別各版本小智，不硬編各階段角色 ID。確認對手後才抽場景的流程不變。

## 使用者追加的介面要求

對戰訊息移除底框；訊息所在的地板是亮色時用純黑、深色時用純白，所有訊息保持不透明，最新一則加粗。從 SVG 產生器的地板色計算相對亮度並選擇黑白對比較高者，輸出專用 CSS 變數，不沿用頂部字色（熔岩天空與地板亮度不同）。既有 React SPA、一般 CSS、自訂變數，不增加套件。

單場勝敗／平手、完整通關／失敗與獎勵背景統一使用選對手的 `rgba(0,0,0,.85)` 與 8px 模糊。結果與獎勵標題改用淺色，保留卡片底色和最終對戰表無滑桿行為；獎勵效果原為淺灰字配淺色卡片，限定該段改用既有深色 `#245356`。
