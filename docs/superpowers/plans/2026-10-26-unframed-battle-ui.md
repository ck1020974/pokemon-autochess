# 資訊列、勝敗與選敵背景調整

作者要求：上方資訊取消透明框；勝敗不要底色色塊；選完對手後才產生戰場。

目前程式已在 handleOpponentSelect 抽一次戰場；畫面多切一次來自 showOpponentSelect 強制切成營地。刪除此切換，選敵期間保留備戰背景；舊場地 class 僅在戰鬥或最終勝敗使用，避免殘留在備戰棋盤。

- 上方資訊保留文字及操作，取消面板背景、底線、圓角、陰影與模糊。
- 單場勝、敗、平及整局冠軍／失敗顯示不再遮住原戰場；保留文字與操作，移除整片底色與裝飾層。最終結果維持最後戰場背景；結算資訊區仍可操作。
- 選敵前後背景不變，選定敵人後只決定一次；進場演出、實戰及重繪沿用同一張。
- 先以瀏覽器驗證現況失敗，再修正，驗證桌機／手機、實際勝敗與最終結算。
- 更新與新意圖矛盾的舊 CSS 字串斷言，執行場地規則及 build；檢查通過後沿用授權更新 GitHub Pages。
- 追加作者要求：最終對戰資訊表取消滑桿，移除巢狀捲動，長紀錄仍可手勢／滾輪查看，十二欄圖示可隨寬度縮小而不裁切；雙方隊伍拉開間距並適應窄橫向畫面；備戰圓盤改深色，對戰圓盤顏色維持原樣。

不改遊戲數值、戰鬥規則、旁白或場景 SVG 圖稿。
