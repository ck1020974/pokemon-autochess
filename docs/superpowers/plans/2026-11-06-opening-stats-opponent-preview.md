# 開場數值、對手預覽與小智皮卡丘修正計畫

1. 先以正式／背景模擬器重現正負電拍拍受較早開場效果影響而放大／縮小傳遞值；新增各星數、雙側、封印與首位不自我加成案例。
2. 在戰鬥副本完成建立與敵方難度縮放後、任何開場效果前記錄攻擊／生命上限快照，幫助僅讀此快照；比例與向下取整保留，兩套模擬器同步。
3. 在顯示對手選項時生成並保存各選項的實際陣容；預覽取其中前三位，確認選擇後出場與實戰沿用同一份，不重新抽隊。重新開局時清空保存陣容。
4. 在敵隊完成升星後，僅對實際對手名為小智的皮丘家族套用皮卡丘模板，保留星數／難度成長並移除該實例的後續進化連結。涵蓋指定及隨機備援對手；其他對手與玩家的模板不變。
5. 驗證全三版本的小智、其他訓練家、玩家正常進化，以及瀏覽器中的選項→出場→戰鬥一致性；執行相關既有回歸、建置與審查後部署並核對正式站。
