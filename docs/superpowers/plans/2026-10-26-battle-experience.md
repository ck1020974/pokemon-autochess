# 對戰配置、進場與新手引導

使用者要求：羈絆對齊隊伍、進場加入訓練家與雙方 00 隊伍圖示、手機訊息縮小、教學配置更輕盈。

設計沿用 React 與既有 CSS／SVG，不加動畫套件或生成圖片。羈絆移入所屬 board-side 定位，與隊伍共享中心，避免貼視窗邊緣。進場使用雙方訓練家與下方五格隊伍列，短暫對向滑入、隊伍錯開出現、中央 VS 光線；點擊可略過，尊重減少動態效果設定。

敵方先用現有生成規則準備一次，進場展示這份陣容；開始正式戰鬥直接沿用，避免圖示與實際陣容不同。生成邏輯移至獨立模組，不更動數值規則。手機橫向戰鬥訊息從 .9rem 調為 .75rem。

教學改為右側空白區的小型淡透明提示帶：步驟、學習重點、具體操作分層；桌機與手機皆避開玩家陣容／商店目標，保留既有任務判斷及操作限制。入口提示採一致淺色風格。
