# 七項遊戲修正：實作與驗證

2026-11-07；依作者核准的兩份修正設計實作，未發布網站或重製影片。

## 修改內容

1. **上方資訊列**：準備與戰鬥統一不透明薄荷底、深色文字，移除場景文字陰影與不同底色；保留資訊列置頂、安全區與原生對話框遮罩。
2. **夢幻分身**：取開場快照的最大生命與攻擊，保留星級與動態羈絆。動畫／無動畫引擎一致，沉默不觸發，分身不遞迴召喚。被溶食獸吞下再吐回仍保留同一份開場快照；一般吞下／吐回數值不改。
3. **伊布進化**：隨機進化候選排除隊伍已有三星的相同型態，其他型態保留羈絆加權；處理直接升三星、複數排除與合成消耗來源。
4. **無限模式退場動畫**：未選卡片以 400ms 輕微縮小、下沉與淡出退場，移除鋸齒裁切、旋轉與灰階。選中卡片保留強調；減少動態效果時改用 120ms 淡出。保持兩次點選確認與處理期間禁止重複選擇。
5. **教學介面**：保留原生跳動手指並提供完整繪製空間；移除提示外框、保留局部柔光；刷新提示不再改變按鈕定位。另修正正式教學原有的換位自動補商品問題，只有按刷新才改商品與扣金幣。引導卡、完成畫面的文字與留白調整為一致且可讀。
6. **小剛教學首戰**：三個獨立 ID、真實不同陣容，預覽、入場與戰鬥共用同一組單位；首戰普通與困難顯示鎖定原因，滑鼠、觸控與鍵盤不能確認，處理函式也有防線。後續冠軍教學不受限制。
7. **手機對戰訊息**：訊息寬度限制在實際可用安全區內，縮減空白與間距並避免 flex 壓縮文字；保留寶可夢圖片尺寸與五槽版面。直向仍保留原本的旋轉手機提示。
