# 無限版三種選擇流程：UI／UX 優化計畫

2026-11-03。先提出設計，尚未修改三種選擇介面。現況已以原生流程取得桌面 1280×720、手機橫向 844×390 的六張畫面，證據在影片專案 `output/選擇流程-現況稽核-20261103/`。技術沿用 React、原生 CSS、既有配色及寶可夢／人物／道具圖片，無 Tailwind 或外部元件庫。

## 目標與共同原則

玩家能知道「正在選什麼、選了有何影響、何時生效」，方便比較且降低誤觸。保持既有角色池規則、對手強度、獎勵抽選與遊戲節奏。影片及錄影副本不隨此計畫更動。

三種畫面共用標題／說明、選項區、隊伍摘要及固定確認列，保持字級、選取狀態與操作一致。桌面並排比較；手機橫向使用緊湊圖片、可捲動內容與固定操作列。避免壓縮到小字才能放入。狀態除顏色外也有明確勾選、文字及焦點提示。

## 現況觀察

- 角色池：首回合連選五次，卡片有圖片、名字、羈絆及技能，但沒有本輪進度；加入商店池與立即獲得角色的差異未明示。未選候選會被加入本局排除名單，畫面未清楚提示。每次選擇等待約 0.7 秒的銷毀動畫。
- 對手：卡片主要是人物圖片、名字、英文難度；缺少能支持選擇的隊伍／風險／獎勵資訊。
- 獎勵：道具圖片與文字較突出，部分只標「暫時」，無法直接看出持續到何時、適用哪些隊友及實際收益。
- 三類卡片目前都是可點擊 div，沒有原生按鈕語義及鍵盤選擇支援。
- 手機橫向現況會出現選擇標題與背景頂列資訊重疊。獎勵卡的高度與縮放需特別處理；最終判定以完成動畫後的畫面及矩形量測為準。

## 建議互動方案

| 方案 | 優點 | 代價 |
|---|---|---|
| 保留點卡立即執行，只調整排版 | 最快，改動小 | 細節查看與不可逆選擇容易混淆 |
| 點卡選中／預覽，再按固定確認鈕（推薦） | 三流程一致、可比較、降低誤觸 | 每次多一次確認操作 |
| 桌面懸停看詳情、點擊直接執行 | 熟練玩家快速 | 手機缺少懸停，兩套操作較難理解 |

推薦第二種，不再額外跳「確定嗎」視窗。卡片選中後才啟用確認鈕；確認文字具體寫「加入角色池」「挑戰這位對手」「領取獎勵」。鍵盤 1／2／3 選卡、Enter 確認；鍵盤事件只在該選擇層作用。查看羈絆／詳細資料不觸發確認。換一組候選後重置選中狀態，避免連按誤選下一組。

## 角色池：先清楚表達選擇後果

1. 標題改成「擴充商店角色池」，副標「選到的角色會加入本局商店候選」。
2. 顯示本輪進度，如「第 1／5 次選擇」及實際階級；一旁列出本輪已選角色，持續顯示至本輪完成。
3. 卡片順序固定為名字／階級、適量圖片、技能摘要、羈絆名稱。詳細效果可展開，避免只靠小圖示猜測。
4. 預覽與目前隊伍的關聯，例如「念力計數 2 → 3」；明確註明需買入並上場後才會生效，不能把加入商店池顯示為已啟用羈絆。
5. 固定提示「本次未選的候選角色會從本局候選中排除」。依現有規則提示角色，不擴大宣稱整個家族都被排除。
6. 以約 0.15～0.25 秒的選中回饋取代長銷毀等待，處理期間鎖定重複送出。保留減少動態效果設定。
7. 候選不足時只呈現不同選項；降階補位時顯示角色實際階級，避免重複卡或錯誤階級標示。

## 對手：提供有依據的比較

1. 人物圖縮小，名字、文字難度與重要資訊固定對齊，三張卡可逐行比較。
2. 第一階段顯示資料已定義的核心角色、主要羈絆及獎勵等級；仍有隨機性的內容標示「可能出場／可能獲得」。
3. 後續若展示實際完整陣容與數值，在選敵畫面開啟時為每個候選只產生一次並保存，選定後戰鬥沿用同一隊；切卡、懸停及縮放均不得重新抽選。
4. 陣容維持固定五槽、左右方向及前後順序；雙方同時出現時檢查雙側羈絆相對第 5 槽的位置。不能用圖片順序或螢幕百分比代替槽位。
5. 顯示可解釋的特徵，例如主要羈絆及高攻擊核心；第一版不加入未經驗證的預測勝率或「必勝」推薦。

## 獎勵：讓玩家看懂收益

1. 所有卡片都顯示效果期間：「立即」「下一場戰鬥」「永久」，取代含糊的「暫時」。
2. 名稱下第一行優先顯示主要效果與數值；圖片縮小到能辨識即可，完整原說明保留於細節。
3. 顯示適用對象：全隊／指定羈絆／隨機一名，並在隊伍摘要標出目前可能受益的角色及數量。
4. 確定效果可顯示前後數字；隨機效果只顯示可能結果或範圍，不在預覽階段擲亂數、修改遊戲數值或宣稱確定收益。
5. 目前沒有適用角色時顯示清楚提示，是否仍可選依現有規則處理。預覽與實際效果共用同一套目標／期間定義，避免 UI 自行複製判斷而失準。

## 實作順序

**第一階段：共通體驗。** 修正手機標題重疊與內容高度；建立統一選取／確認狀態、鍵盤與焦點、44px 以上操作範圍。這階段即可減少三個流程的誤觸。

**第二階段：角色池＋獎勵。** 補進度、排除提示、技能摘要、期間與受益對象；提高每次選擇的資訊品質。角色池涉及連續選擇，優先驗證節奏。

**第三階段：對手比較。** 先補核心角色／羈絆與獎勵等級；完整陣容預覽及快取列為後續，避免第一階段同時調整對手產生時機。

## 驗收

- 1280×720、1920×1080、844×390、667×375 檢查；長名字、長說明、單一候選也不遮擋操作。
- 連續選池、快速點擊、查看羈絆、鍵盤 Enter 均只提交一次；選中與懸停外觀可區分。
- 預覽不改金幣、商店、隊伍、獎勵、角色池或亂數結果；按確認才執行。
- 詳細區域可捲動、操作列固定；關閉詳細後焦點回到原卡。
- 對手完整預覽若啟用，與實際開戰角色、槽位、數值及羈絆一致；雙方依第 5 槽逐側核對。
- 上線後可再比較選擇耗時、詳細資訊使用與誤觸回報；第一版不擅自改角色、難度或獎勵數值。
