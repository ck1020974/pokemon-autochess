# 作者觀測站

作者頁是獨立 HTML，不在遊戲選單、首頁或說明中放連結，並帶有 noindex。資料安全依靠 Supabase Auth 與資料庫作者名單；知道網址仍需登入作者帳號。首次由一次性設定連結建立至少 12 字元密碼，設定令牌放在 URL fragment，進頁立即移除，不寫入原始碼。

## 第一版範圍

每日造訪、活躍匿名玩家、合格遊玩局次、戰鬥勝率、完成率、通關率；日期／版本／模式／難度篩選；每日趨勢、羈絆出場樣本與最近 20 局的最後開戰隊伍。空資料顯示零或「—」，不混入示範資料。隊伍保留五槽與空槽，最後開戰快照不代表戰後成長數值。

- 造訪：同分頁三十分鐘無活動後的新區段。重新整理延續原區段。
- 活躍玩家：選定日期內完成戰鬥的不同匿名瀏覽器識別碼。不是精確自然人人數。
- 合格局次：首場正式戰鬥完成後才計入，按台灣日期建立局次群組。
- 戰鬥勝率：勝場／已完成戰鬥，含平手。
- 完成率：已通關或最終戰敗的局次／合格局次。
- 通關率：已通關／已完成整局。不同模式及版本可分開觀察。
- 局次狀態按目前收到的整局結果更新；明確重開或超過 24 小時無更新列為未完成。
- 造訪只依日期篩選，遊戲維度不適用；活躍玩家及戰鬥依完成日期篩選，局次依首次完成日期篩選。

## 收集及權限

遊戲僅傳送隨機識別碼、模式、版本、難度、開戰隊伍／羈絆與結果，不收集玩家姓名、電子郵件或 IP。教學、本機開發及自動瀏覽器預設不收集；作者頁不記錄遊戲造訪。瀏覽器 `pokemon-analytics-opt-out=1` 可停用。離線事件保留七天內、最多 500 筆，超過期限不回補。清除瀏覽器資料或換裝置會產生新識別碼。

Edge Function `pa-ingest` 自行驗證 publishable key、來源、大小與資料型別，只能寫入事件。資料表以 RLS 禁止公開查詢及直接寫入；作者名單只能由管理工具修改。去重涵蓋事件 ID 及同一局／回合的邏輯事件。臨時作者初始化函式已停用為固定 404，無任何前端管理金鑰。

## 驗證與維護

`npm run test:analytics`、`npm run test:author-ui`、`node scripts/verify-analytics-game.mjs`、`node scripts/verify-analytics-live.mjs`。原生遊戲整合測試使用本機 5182 服務，僅在攔截的測試模組啟用追蹤，不寫入正式統計。

`scripts/build-analytics-db-test.mjs <作者 UUID>` 產生 `analytics-db-test.local`，以交易測試 RLS、匿名權限、重送、台灣日期、跨午夜活躍玩家、分母與空槽，最後 rollback。雲端接收測試事件標記 is_test，因此不影響正式數字。截圖與驗證 JSON 存於影片專案 `output/作者統計頁-20261103/`，頁面測試截圖在遊戲目錄 `output/playwright/author-dashboard/`，並標明測試資料。

Supabase 專案：`jhyqpizbvbwikvalqxpy`；已套用兩份 migrations。部署 Edge Function 時使用隨附 deno.json，verify_jwt=false 是因為函式自行驗證現代 publishable key；不可移除函式內驗證。作者頁不提供公開註冊。若設定連結失效，需由作者授權的管理流程重新產生 recovery link。

瀏覽器回報適合觀察趨勢，不作競賽認證；部署前的歷史遊玩無法補算。正式資料從此次部署開始累積。
